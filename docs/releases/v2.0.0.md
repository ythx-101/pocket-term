# Pocket Term v2.0.0 发布说明

- 发布版本：`v2.0.0`
- 发布对象：当前正在运行的 Pocket Term Web
- 发布状态：待完成 Git tag 与最终发布门禁

## 本版本内容

- 手机端会话列表、消息气泡、Tier A/Tier B 消息流和 SSE 更新
- 受保护的 pane 消息发送与只读熔断
- 图片上传和图片预览
- Markdown 附件安全预览
- HTML 附件白名单清洗、sandbox 隔离和独立预览窗口
- 可选 Web Push 通知
- 运行时付费答疑群入口

## 付费答疑群

- 群名：**QingYue skill 答疑群**
- 单价：**55 元**
- 二维码：只作为运行时资源，不提交到 Git 或发布包
- 有效期：以 Web 页面当前显示内容为准

当以下运行时配置全部存在时，Pocket Term 的“我”页面显示入口：

```text
PT2_PAID_GROUP_NAME
PT2_PAID_GROUP_PRICE
PT2_PAID_GROUP_QR_PATH
PT2_PAID_GROUP_EXPIRES
```

二维码路径必须位于文件白名单根目录下，并通过图片扩展名、realpath、symlink 和大小检查。

## 安全边界

- 默认监听 `127.0.0.1:7690`
- 不把二维码、VAPID 私钥、运行时状态或上传数据提交到 Git
- Markdown 内容不执行原始 HTML、脚本或图片
- HTML 预览使用白名单清洗和空 sandbox
- 上传与文件读取限制扩展名、大小、路径穿越和 symlink escape

## 验证

```bash
node --check server.js
node --check public/app.js
npm test
```

发布前必须记录实际测试数量、完整退出码、systemd PID、`/herd/api/state`、SPA、SSE 和二维码接口健康结果。

## 回滚

不移动或删除已发布 tag。代码异常时使用独立 Git revert commit，恢复上一已验证版本后，在批准窗口内重启 `pocket-term-2.service`，再重复健康检查。二维码和 `state/`、上传目录不随代码回滚删除。
