# Pocket Term v2.0.0 发布说明

- 发布版本：`v2.0.0`
- 发布日期：2026-07-23
- 发布对象：当前正在运行的 Pocket Term Web
- 发布状态：已完成生产验证，正式发布到 GitHub `v2` 分支、`v2.0.0` tag 与 Release

## 本版本内容

- 手机端会话列表、消息气泡、Tier A/Tier B 消息流和 SSE 更新
- 受保护的 pane 消息发送与只读熔断
- 图片上传和图片预览
- Markdown 附件安全预览
- HTML 附件白名单清洗、sandbox 隔离和独立预览窗口
- 可选 Web Push 通知
- 运行时付费答疑群入口
- Clear Lavender 深浅主题：强化背景、表面、边框、文字和状态层级
- 统一 `工作中` / `等你回复` 状态语义、键盘焦点与减少动态效果支持
- 保留手机端紧凑快捷键：`Esc`、`Ctrl+C`、`↑`、`↓` 使用 28px 高度

## 安全边界

- 默认监听 `127.0.0.1:7690`
- 不把二维码、VAPID 私钥、运行时状态或上传数据提交到 Git
- Markdown 内容不执行原始 HTML、脚本或图片
- HTML 预览使用白名单清洗和空 sandbox
- 上传与文件读取限制扩展名、大小、路径穿越和 symlink escape
